SmoothLifeL

HackerTube summary: Tim Hutton's demonstration of SmoothLifeL, a continuous version of Conway's Game of Life using floating point values. It shows gliders traveling in any direction, rotating pairs, and elastic cord-like structures, with config details to run it yourself.
