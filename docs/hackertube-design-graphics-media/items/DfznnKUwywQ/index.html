Computational Design of Mechanical Characters

HackerTube summary: A Disney Research SIGGRAPH 2013 demo of an interactive system that lets non-experts design animated mechanical characters. The user sketches motion curves and the system generates optimized mechanisms and gear trains for 3D printing.
