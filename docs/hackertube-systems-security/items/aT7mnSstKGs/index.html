DEFCON 19: Bit-squatting: DNS Hijacking Without Exploitation (w speaker)

HackerTube summary: Artem Dinaburg's DEF CON 19 talk on bit-squatting, where flipped bits in DRAM cause devices to contact domains that differ by one bit from legitimate ones. He shows how registering such domains can hijack traffic without exploiting any software bug.
