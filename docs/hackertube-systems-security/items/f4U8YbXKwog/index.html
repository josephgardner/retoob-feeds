Qubes OS: The Operating System That Can Protect You Even If You Get Hacked

HackerTube summary: Micah Lee's Circle of HOPE 2018 talk on Qubes OS, which isolates activities in separate virtual machines so one compromise, such as a bad PDF or USB stick, does not expose everything. He gives an overview timed around the Qubes 4.0 release.
