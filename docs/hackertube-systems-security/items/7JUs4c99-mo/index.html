CheerpX: a WebAssembly-based x86 virtual machine in the browser, Yuri Iozzelli

HackerTube summary: A talk by Yuri Iozzelli at a WebAssembly meetup on CheerpX, an x86 virtual machine running in the browser. It uses a JIT compiler that emits WebAssembly at runtime to run real native applications. It covers the architecture and demos such as porting a multiplayer C++ game.
