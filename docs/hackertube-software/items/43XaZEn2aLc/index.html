On the Expressive Power of Programming Languages by Shriram Krishnamurthi [PWLConf 2019]

HackerTube summary: Shriram Krishnamurthi's PWLConf 2019 talk on the formal notion of expressive power of programming languages, based on Felleisen's paper.
